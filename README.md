b站动态分组筛选助手

在B站动态页面按关注分组筛选动态的油猴脚本。

## 功能

- 按关注分组筛选动态，只显示指定分组的动态内容
- 支持多分组同时筛选（成员取并集）
- 分组搜索：分组较多时可快速搜索定位
- 自动加载：向下滚动时自动拉取更多历史动态
- 分组成员缓存：减少重复 API 请求
- 实时统计：显示已过滤/已展示的动态数量

## 使用方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 将 `B站动态分组筛选助手.js` 的内容复制到 Tampermonkey 新建脚本中保存
3. 访问 [B站动态页面](https://t.bilibili.com/)
4. 点击右上角「📁 分组筛选」按钮打开面板
5. 点击分组进行筛选（支持多选），刷新页面生效
