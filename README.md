# B站动态分组筛选助手

在 B 站动态页面按关注分组筛选动态的浏览器用户脚本，支持 Violentmonkey 和 Tampermonkey。

当前版本：`18.0.0`

本项目是非官方工具，与哔哩哔哩官方无关。

## 安装

1. 安装 [Violentmonkey](https://violentmonkey.github.io/) 或 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击下面的链接直接安装或更新：

   [安装 B站动态分组筛选助手.js](https://raw.githubusercontent.com/chenlan432/BilibiliDynamicGroupFilterHelper/main/B%E7%AB%99%E5%8A%A8%E6%80%81%E5%88%86%E7%BB%84%E7%AD%9B%E9%80%89%E5%8A%A9%E6%89%8B.js)

3. 打开 [B 站动态页](https://t.bilibili.com/)，点击右侧的「分组筛选」按钮。

也可以从 [GitHub 源码](https://github.com/chenlan432/BilibiliDynamicGroupFilterHelper) 复制脚本内容后新建用户脚本。

如果你正在使用 v17.x，旧版没有配置自动更新地址，首次升级需要点击上面的安装链接覆盖安装一次。v18 之后可以由脚本管理器检查 `@updateURL`。

## 使用

- 可以同时选择多个关注分组，筛选结果为这些分组关注者的并集。
- 先勾选分组，再点击「应用筛选并刷新」；批量选完多个分组后一次性应用，避免重复刷新。
- 分组较多时可以使用搜索框快速定位。
- 选择「全部动态」并应用，即可取消筛选。
- 「刷新动态」只刷新页面；「清除成员缓存」会删除本地成员缓存并在刷新后重新拉取。

## 行为说明

- 分组成员默认缓存 1 小时，减少重复请求。
- 自动补页最多扫描 10 页、最多持续 6 秒，并统一限制请求间隔，避免高频请求触发 B 站风控。
- 网络错误、登录失效或请求受限时，已选分组不会被自动清空。
- 如果筛选处理失败，脚本会暂时显示原始动态并提示错误，避免把 B 站动态流变成空白。
- 分组名等动态内容全部通过 DOM 文本节点渲染，不使用动态 `innerHTML`。
- 面板支持窄屏布局、键盘操作和系统/页面深色模式。

脚本只向 `api.bilibili.com` 请求关注分组和成员数据，选择与成员缓存保存在用户脚本管理器本地，不会上传到其他服务。

## 已知限制

- 功能依赖 B 站动态页当前的 `fetch` 接口和 `/x/relation/*` 接口；接口变更后脚本可能暂时失效，此时会回退显示原始动态并在面板中提示。
- 很小的分组在大量不相关动态中可能需要多次扫描。为避免风控，单次扫描有页数和时间上限；达到上限仍无匹配时，刷新页面可以重新尝试。
- 分组成员缓存有效期内，新增加或移出的关注成员可能尚未反映到筛选中。

## 开发

项目不需要构建，直接编辑单文件脚本即可发布。需要 Node.js 18 或更高版本运行测试。

```powershell
npm run check
npm test
npm run verify
```

在浏览器控制台执行下面的命令并刷新页面，可以打开调试日志：

```js
localStorage.setItem('GF_DEBUG', '1')
```

关闭日志：

```js
localStorage.removeItem('GF_DEBUG')
```

## 版本记录

### v18.0.0

- 重构请求层：统一请求节流、有限重试、超时、取消和 B 站错误分类。
- 重构成员缓存：只在完整拉取时更新，网络失败时保留旧缓存和用户选择。
- 自动补页增加页数与时间预算，遇到 412、429、`-352` 等风控状态时停止继续请求。
- 分组选择改为“批量选择后应用”，消除快速连续点击产生的异步竞态。
- 动态分组名改为安全 DOM 渲染，移除 `innerHTML` 和数据属性字符串拼接。
- 修复重组响应时复制 `content-length`、`content-encoding` 等不匹配响应头的问题。
- 增加加载态 `finally` 恢复、响应式布局、键盘操作、深色模式和行内状态提示。
- 增加 Node 单元测试、README、MIT 许可证和脚本更新元数据。

### v17.0

- 支持多分组筛选、分组搜索和自动补页。
- 增加分组成员缓存和过滤统计。
